# general-protocols

Communication protocols, rules, skills, agents, and guides for the General
teamspace at Ametyst.

## Layout

- `rules/` — copied into user's `.claude/rules/`
- `skills/` — copied into user's `.claude/skills/`
- `agents/` — copied into user's `.claude/agents/`
- `guides/` — reference docs (read on demand)
- `CLAUDE.md` — snippet merged into user's CLAUDE.md

## Maintainer

Head of General. Team members open PRs; only the head merges to `main`.
